\section*{Governance}
No \texttt{CLAUDE.md}/\texttt{CORE.YAML}/\texttt{tools.yaml} in \texttt{graph}; core's
\texttt{CLAUDE.md} applies as the minimum. This plan is on disk \emph{before} the
first \texttt{meta\_resolve.rs} edit. \texttt{plan.pdf} waived (no LaTeX). Base HEAD
\texttt{a125275}; \texttt{Cargo.toml} sha256 \texttt{095e27db}, \texttt{Cargo.lock}
sha256 \texttt{c2492761} --- both held byte-identical.

\paragraph{ETA.} $\approx$3\,h: plan 15\,m, tests-first 45\,m, migration 45\,m,
fault-injection 20\,m, coverage 15\,m, perf A/B 25\,m, report 15\,m.

\section{Scope}
Migrate every raw IR-storage read in \texttt{hymeko\_pgraph/src/meta\_resolve.rs}
to the storage-independent accessor API of core \texttt{15223bc}; make the strict
consumer report malformed IR as a \emph{typed} error instead of an empty result
(\texttt{GRAPH-DEFECT-01}) or a panic (\texttt{GRAPH-DEFECT-02}); preserve valid
output byte-for-byte. Only \texttt{meta\_resolve.rs} (and \texttt{lib.rs} if a
re-export is needed). No \texttt{hymeko\_graph}, core, parser, manifest, lockfile,
algorithm, or ID change.

\section{Typed error model}
\texttt{IrReadError}: \texttt{Debug\,+\,Copy\,+\,Clone\,+\,Eq\,+\,PartialEq},
ids/\texttt{DeclKind} only (no names, no attacker text), \texttt{std::error::Error};
wrapped by \texttt{MetaResolveError::Ir(IrReadError)} exposed via \texttt{source()};
no allocation on valid IR. Distinguished variants: \texttt{DanglingDeclaration},
\texttt{MissingNodeMapping}, \texttt{MissingEdgeMapping}, \texttt{MissingNodeRecord},
\texttt{MissingEdgeRecord}, \texttt{NodeBacklinkMismatch}, \texttt{EdgeBacklinkMismatch},
\texttt{DanglingArcRecord}, \texttt{ArcOwnershipMismatch} (\texttt{ArcRec::in\_edge}),
\texttt{DanglingBaseTarget}, \texttt{DanglingIncidenceTarget}. No two collapsed
into one \texttt{None}/\texttt{MalformedIr}.

\section{Helper flow (fallible)}
\texttt{bases\_of}, \texttt{isa\_reaches}, \texttt{unit\_arc\_refs},
\texttt{unit\_arc\_targets}, \texttt{edge\_cost}, \texttt{decl\_kind},
\texttt{decl\_name}, \texttt{register} become \texttt{Result<\_, IrReadError>};
\texttt{classify\_materials/units}, \texttt{build\_incidence}, \texttt{find\_decl},
\texttt{lower\_resolved} thread \texttt{?} (\texttt{IrReadError}$\to$%
\texttt{MetaResolveError} via \texttt{From}). Dense scans use \texttt{ir.decls()}.
\texttt{isa\_reaches} becomes \emph{iterative} with the same visited-set cycle
guard --- preserving the exact reachability result and cycle-safety while removing
the recursion stack-depth limit (so inheritance depth 1024 resolves). This is a
documented decision, not a silent change (\S E of the brief); a permanent test
pins cycle termination and the depth ladder.

\section{Semantic invariants (must not change on valid IR)}
Declaration classification; raw/product/intermediate/process roles; inheritance
traversal result; \textbf{arc declaration order}; \textbf{ref slot order}; $+/-/\sim$
sign handling; costs; \texttt{name\_to\_decl}; P-graph node/edge ids; MSG/SSG/ABB
output; dump format \& ordering. No \texttt{sort}/\texttt{map}/\texttt{set} inserted on
the arc/ref path. \texttt{ArcRec::in\_edge} ownership becomes a typed error when an
edge lists an arc owned by another edge.

\section{Test matrix}
Tests-first (characterization against the original), then permanent regressions.
Valid: end-to-end \texttt{compile\_to\_lowered}/\texttt{compile\_sources}/%
\texttt{lower\_resolved}, path==memory-provider, multi-file, inheritance depth
1/64/65/128/1024, multi-arc, multi-ref, duplicate incidences, $+/-$ order, neutral
ref error, scalar/absent cost, raw/product conflict, ambiguous/missing archetype.
Malformed (exact \texttt{assert\_eq!} on the variant): out-of-range \texttt{DeclId},
\texttt{DeclId::NONE}, missing node/edge mapping, mapped-missing record, node/edge
backlink mismatch, dangling arc id, arc-owner mismatch, dangling base target,
dangling incidence target, inheritance cycle, empty/partial IR. Order fixtures are
\emph{non-symmetric} (swapping arcs/refs/signs changes the expected output).
Oracle: 6 dump hashes (methanol/hda $\times$ msg/ssg/abb) byte-identical, plus
cardinalities. Fault injection: 4 mutants (drop backlink check; missing arc$\to$empty;
swap arc/ref order; ignore dangling target), each caught by a named test, none
committed (restore verified by hash).

\section{Performance plan}
Resident \texttt{lower\_resolved} (no parser) and end-to-end
\texttt{compile\_sources}, over the 6 fixtures plus small/medium/large synthetic
valid workloads. std-only probe, no new dependency, not part of the public API.
IR prep and hash check outside the timed region; release build; alternating A/B,
$\ge$6 paired rounds; A/A null; ambient load before/after; median + paired delta.
Gate: worst valid-hot-path regression $<3\%$; no new heap allocation on the valid
path; a $>3\%$ cell is a regression until profiled and isolated; Amaterasu
(\texttt{kyberszittya@192.168.1.228}) available if the local host can't resolve 3\%.

\section{Rollback / stop}
Only \texttt{meta\_resolve.rs} (+ maybe \texttt{lib.rs}) is production-tracked;
rollback is \texttt{git checkout -- }. Stop and do not commit if: any oracle hash
changes without a stated requirement; a valid cardinality changes; a $>3\%$
regression survives isolation; the manifest/lockfile would change; a raw read
remains.

\section{Forbidden}
\texttt{unsafe}; \texttt{unwrap}/\texttt{expect}/\texttt{panic!} in new non-test code;
lint/coverage suppression; silent old-behavior fallback; needless public
alias/factory; new dependency; manifest/lockfile change; touching
\texttt{hymeko\_graph}/core/parser.
