\section*{Goal}
Canonical topology \textbf{only} in \texttt{Ir + IncidenceIndex}; PGRAPH holds \textbf{only} domain state
(classification, costs, regimes, MSG/SSG/ABB policy); input/output/producer/consumer/degree/reachability run
\textbf{only} through \texttt{PGraphView}; \texttt{schema.incoming/outgoing} not persistent authoritative state.
\section*{Audit (blast radius + three hard constraints)}
\texttt{PGraphSchema} owns five topology/partition fields: \texttt{edges}, \texttt{incoming}, \texttt{outgoing}
(topology), \texttt{o\_nodes}, \texttt{m\_nodes} (partition); plus \texttt{nodes} (kinds = domain). Consumed by
\texttt{axioms, axiom\_extensions, msg, ssg, ssg\_dm, abb, dump, cli, pgip\_io, regime, lowering}. Three hard
constraints make this a large \emph{breaking} refactor of the feasibility kernel:
\begin{enumerate}
\item \textbf{Self-referential lifetime.} No struct can own \texttt{Ir} \emph{and} \texttt{IncidenceIndex<'borrowing-self>};
the model cannot bundle them. The caller must hold \texttt{Ir} $\to$ \texttt{index} $\to$ \texttt{view} as
separate locals.
\item \textbf{Public API break.} \texttt{compile\_to\_lowered(path) -> LoweredPGraph} cannot return a
\emph{borrowed} value (its internal \texttt{Ir} would drop). It must return a bundle owning the \texttt{Ir}.
\item \textbf{Zero-alloc borrowed returns.} \texttt{predecessors/successors/inputs/outputs/producers/consumers}
return \texttt{\&BTreeSet}; MSG/SSG/ABB use them in \texttt{.iter().all()} AND-folds and set ops. Deriving
on-demand from \texttt{edges} would both change the return type and allocate --- so the rewire must move these
folds onto \texttt{PGraphView}'s \texttt{for\_each\_*} callbacks (touching the AND-closure kernel).
\end{enumerate}
\section*{Chosen design (lowest lifetime/API burden that guarantees one topology)}
\textbf{\texttt{PGraphDomain}} (owned: kinds, raws, products, materials, units, costs, cost\_dimensions,
cost\_vectors, name maps --- \emph{no topology}) $+$ \textbf{\texttt{PGraphView<'ir,'idx>}} (borrowed topology,
already built P1.2/P1.3), delivered via a \textbf{\texttt{CompiledPGraph}} bundle owning \texttt{Ir} $+$
\texttt{PGraphDomain}. \texttt{compile\_to\_lowered} $\to$ returns \texttt{CompiledPGraph}; the caller builds
\texttt{IncidenceIndex} $+$ \texttt{PGraphView} from \texttt{\&bundle.ir}. Preferred over
\texttt{LoweredPGraph<'ir>} because the latter cannot own the index (self-referential) and forces the lifetime
through every domain type; the bundle localizes the API change to one struct $+$ a build-view step.
\section*{Consumer rewire (mechanical, byte-identical-gated)}
MSG/SSG/ABB/axioms take \texttt{\&PGraphView} ($+$ \texttt{\&PGraphDomain} for classification/cost); the
\texttt{p.inputs(u).iter().all(...)} AND-folds become \texttt{view.for\_each\_input(u, ...)} callback folds ---
\textbf{semantically + byte-identical} (the AND-closure feasibility logic is preserved; only its topology source
changes). Remove \texttt{PGraphSchema.\{edges, incoming, outgoing, o\_nodes, m\_nodes\}}; the model then retains
\textbf{zero} topology.
\section*{Proof gate (§2)}
grep: zero \texttt{BTreeMap/BTreeSet} topology field in the running model; retained-memory A/B (removes 2
adjacency \texttt{BTreeMap}s $+$ \texttt{edges} $+$ 2 partition \texttt{BTreeSet}s $\to$ topology memory $=$ the
\texttt{IncidenceIndex} only); six dump hashes; \texttt{.pgip} round-trip; MSG/SSG/ABB result identity;
BooleanExact $+$ fuzzy set-invariance; duplicate/sign/order preservation; malformed-\texttt{Ir} typed errors;
warm-query zero-alloc; independent traversal oracle; fault mutants against re-introducing dual authority.
\section*{Scope decision (honest)}
This touches the AND-closure feasibility kernel (\texttt{.all()} folds in \texttt{msg/ssg/ssg\_dm/abb}) across
$\sim$8 files with a public-API break and a strict byte-identical gate. It is \textbf{specified and ready} above
and is \emph{safe to execute} (the golden dump/pgip/MSG/SSG/ABB tests catch any behavioural break immediately),
but it is a focused multi-file effort that must be done with continuous per-file byte-identical re-verification
--- not rushed alongside the other overnight phases. Delivered here as the executable design $+$ measured
foundation; the P1.2/P1.3 \texttt{PGraphView} parity (adjacency $+$ reachability $+$ degree $==$ schema) is the
proven precondition. \textbf{Recommended next: execute this as its own dedicated change.}
