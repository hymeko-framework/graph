\section*{Semantic contract (see semantic-contract.md)}
State space: implicit incidence \texttt{node $\to$ (arc,slot) $\to$ node}; forbidden: explicit Levi/star/
clique, dropping sign/weight/slot/duplicate, dense-id reinterpretation. Cost: typed, finite, non-negative
(\texttt{NaN}/$\pm\infty$/negative $=$ typed error), exit-independent-separable primary model
($c=w_{arc}+w_{entry}$) enabling arc-activate-once ($O(\text{incidences})$); metric/general path relaxes per
member. Policy: undirected / sign-compatible / directed producer$\to$consumer / consumer$\to$producer /
domain --- filter only, chosen once (no runtime mode boolean, no \texttt{Box<dyn>} in the hot loop). Order:
\texttt{f64::total\_cmp} then \texttt{(discrete\_tiebreak, DeclId, HyperArcId, slot)}. Reopen: consistent-
heuristic fast path; an inconsistent heuristic in optimal mode is a typed rejection (fail-closed), not a
silent sub-optimal path.

\section*{Performance budget / gates (§12)}
Correctness first (optimal cost identical on every oracle cell). A* production-retention requires: warm
query allocation-free; no materialised adjacency; on a metric-friendly or discrete-friendly workload
$\ge 2\times$ fewer expanded states \emph{or} $\ge 20\%$ wall improvement vs Dijkstra; on an uninformative
heuristic $\le 10\%$ overhead vs the Dijkstra engine (or a separate zero-heuristic fast path); memory
$O(\text{nodes}+\text{arcs})$; \textbf{no} $>3\%$ regression in any untouched direct\_ir op. The goal is that
the \emph{benchmark selects} where a heuristic pays --- not that every heuristic always wins.

\paragraph{Exact semantics.} Let a(v,e) be a nonnegative source incidence mass and
b(v,e) a nonnegative destination mass, counting duplicate slots. Select an active
incident arc proportionally to a, then a member proportionally to b. An arc with
zero destination mass cannot be selected; a node without active outgoing mass is
dangling. Default: unit masses, every sign/port allowed, including a return to the
same vertex. This is the Zhou et al. (NIPS 2006, section 4) incidence walk, with
PageRank teleportation. Directed pairwise arcs with one source and destination
recover ordinary directed PageRank. Do not claim the undirected return-permitting
walk equals no-self-loop pairwise PageRank at the same damping.
Optional routes: minus-to-plus and In-to-Out, independently selectable; no inference
of port direction from sign. Weights are explicitly unit or one numeric vector
component; absent vectors default to one, present missing/nonnumeric/negative or
nonfinite components fail. Personalization is normalized, finite, nonnegative and
nonzero. Dangling mass follows that same personalization.

\paragraph{API and complexity.} PageRank::build borrows immutable Ir and validates
node targets, then prepares only degree/arc normalizations and optional numeric
weights. PageRank::run accepts typed iteration configuration, reusable workspace
and optional personalization. No clique/adjacency expansion. Each iteration is
O(V+E+I); scratch O(V), preparation O(V+E), plus O(I) only for component weights.
One iteration loop owns all routing variants. Compensated sums protect long
reductions. Report iterations, L1 step change, convergence and the contraction
error bound alpha/(1-alpha) times the last change. Iteration cap returns a clearly
nonconverged result. Finite alpha in [0,1), positive tolerance and nonzero cap.
Empty graphs and alpha zero have explicit zero-iteration results.
