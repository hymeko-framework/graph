\section{Decision and authority}
The user requires one current \texttt{hymeko\_core} identity throughout the
HyMeKo--Graph--Nagare chain and has explicitly authorised carrying the canonical
integration through.  The existing Graph checkout was first fetched and
fast-forwarded without creating a worktree.  At entry, Graph
\texttt{main=origin/main=2b619a39} is clean, but its sole root manifest still
pins Core \texttt{92383b38}; canonical Core is
\texttt{main=origin/main=fc3eda9b}.  This boundary performs only that provider
refresh and its generated lockfile update.

\section{Scope and ownership}
Owned paths are \texttt{Cargo.toml}, \texttt{Cargo.lock}, this plan bundle, and
one result report.  No graph algorithm, public API, IR type, benchmark, dataset,
or Nagare production path changes here.  No new worktree, dependency family, or
source alias is introduced.  If Cargo resolves more than one HyMeKo/Core
identity, or moves unrelated packages, the update is rejected and reduced.

\section{Execution}
\begin{enumerate}
  \item Replace the single \texttt{hymeko\_core} revision by
        \texttt{fc3eda9b73e4f171aada5c79751af481759c068e}.
  \item Regenerate only the corresponding lock entry and inspect the exact
        diff before continuing.
  \item Run locked metadata and prove one \texttt{hymeko\_core} instance.
  \item Run the focused direct-IR tests, then full workspace tests, clippy,
        formatting, and governance gates.
  \item Commit and push only if every new failure is absent or demonstrated as
        entry-baseline-equivalent.  Re-fetch and verify local equals remote.
  \item Only then advance both Nagare Graph declarations together and re-run
        Nagare's single-instance gate before Slice 2 implementation.
\end{enumerate}

\section{Acceptance and rollback}
Acceptance requires Graph and its lock to resolve exactly one Core at
\texttt{fc3eda9b}, no duplicate \texttt{hymeko\_*} package, unchanged graph
behaviour, and a clean scoped diff.  The rollback unit is the single dependency
commit; no history rewrite or broad restore is permitted.

\section{Scientific boundary}
