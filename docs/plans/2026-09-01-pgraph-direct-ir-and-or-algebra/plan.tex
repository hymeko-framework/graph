\section*{Semantic contract}
\textbf{Adjacency (from the canonical incidence, sign convention verified against
\texttt{meta\_resolve::build\_incidence}):} for a unit edge-decl $u$, iterate its arc refs ---
$\text{sign}<0$ (\texttt{-}) is a consumed \emph{input} ($m\to u$), $\text{sign}>0$ (\texttt{+}) a produced
\emph{output} ($u\to m$), $\text{sign}=0$ (\texttt{\~{}}) is a typed \texttt{NeutralRef} error.
$\text{producers}(m)=\{u:\text{$m$ is a }+\text{ ref of }u\}$, $\text{consumers}(m)=\{u:\text{$-$ ref}\}$,
via \texttt{IncidenceIndex::incident\_arcs}. The \texttt{+/-/\~{}} sign is an \textbf{incidence role, not a
fuzzy truth value}.

\textbf{Algebra:} $\text{ready}(u)=\bigwedge_{m\in\text{in}(u)}\text{avail}(m)$ (T-norm fold);
$\text{avail}(m)=\text{init}(m)\ \vee\ \bigvee_{u\in\text{prod}(m)} T(\text{ready}(u),\text{rel}(u))$
(S-norm fold), $\text{init}(m)=1$ iff $m$ raw. \textbf{BooleanExact}: $T=\min$, $S=\max$, values in
$\{0,1\}$, $T$-identity $1$, $S$-identity $0$. Fixpoint by monotone worklist.

\textbf{Norms:} BooleanExact (exact) $\subset$ G\"odel($\min/\max$) $\mid$ Product($ab / a{+}b{-}ab$) $\mid$
\L{}ukasiewicz($\max(0,a{+}b{-}1)/\min(1,a{+}b)$). Fuzzy modes give relaxation / priority / bound / search
order \textbf{only}; they never silently change the exact result set. \texttt{NaN}/\texttt{Inf}/
$\notin[0,1]$ is a typed error. Fold order deterministic (sorted). Duplicate incidence stays semantic ---
\textbf{Product mode does not deduplicate}.

\textbf{Convergence:} BooleanExact monotone in $\{0,1\}$, finite. Fuzzy: monotone bounded by $1$; stop on
$\varepsilon$-change with an iteration limit; exceed $\Rightarrow$ typed \texttt{NonConvergent}. Cycle-safe
(re-enqueue only on a strict increase).
